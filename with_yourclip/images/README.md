# 角色图放这里

把**原创**角色图（PNG，透明背景）放进本目录，然后在仓库根目录运行：

```powershell
.\with_yourclip\make-clip-assets.ps1
```

## 要求

| 项 | 要求 |
| --- | --- |
| 格式 | PNG，**必须有透明通道**（JPG 不行） |
| 尺寸 | 短边 ≥ 160px，越大越好 |
| 构图 | 角色完整、四周留一点空白；不用自己裁边，脚本会自动裁到主体 |
| 数量 | 1–9 张，有几张轮换几张 |
| 命名 | 按文件名排序决定顺序，想控制顺序就加 `1-`、`2-` 前缀 |

## 说明

- 这里是**唯一一份**原始图，会提交进仓库。
- 生成的 `src\assets\basket-clip*.png` 是构建产物，不进仓库（避免同图存两份）。
- 换成别人的图之前，请确认你有权使用并分发。
